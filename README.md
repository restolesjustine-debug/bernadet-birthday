# For Bernadet, with love ♡

Elegant mobile-friendly 21st birthday page with the birthday letter, two photos, Proverbs 3:5–6, and animated falling petals.

## GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select `main` and `/(root)`, then Save.
4. After deployment, visit https://restolesjustine-debug.github.io/bernadet-birthday/.

Optional music: add a royalty-free instrumental file named `music.mp3` to the repository root. The music button will play it after being tapped.

Privacy: the repository and website are public. Only share photos you are comfortable making public.
